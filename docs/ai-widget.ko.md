# AI로 위젯 만들기

원하는 위젯을 말로 설명하면 AI가 Scriptable 스크립트를 쓰고, 앱이 **실제 엔진으로 실행해 위젯이 그려지는지 확인**합니다. 만든 스크립트는 일반 스크립트라 편집기에서 얼마든지 고칠 수 있습니다.

**내 스크립트** 탭 → **+ 새 스크립트** → **✨ AI로 만들기**

방법은 두 가지입니다.

| | 프롬프트 복사 (무료) | 앱에서 바로 (API 키) |
|---|---|---|
| 필요한 것 | 아무 AI 채팅 앱(ChatGPT, Claude, Gemini 등) | Gemini·Claude·OpenAI 중 하나의 API 키 |
| 비용 | 없음 (채팅 앱의 무료 사용 범위) | 서비스 요금. Gemini는 무료 등급이 있습니다 |
| 오류가 나면 | "고쳐 달라는 프롬프트"를 복사해 채팅에 다시 붙여 넣기 | 앱이 오류를 AI에 보내 **자동으로 최대 3번** 고칩니다 |

## 1. 무엇을 만들지 적기

**어떤 위젯을 만들까요?** 칸에 적습니다. 예시 버튼을 눌러 시작해도 됩니다.

잘 되는 요청:
- **보여 줄 것과 배치**를 함께: "서울 오늘 날씨, 기온은 크게, 최고·최저는 아래에"
- **데이터 출처**를 알면 적기: "Frankfurter API로 달러 대비 원·엔 환율"
- **조건과 색**: "배터리 잔량을 막대로, 20% 아래면 빨간색"
- **크기**: "작은 위젯에 맞게"

잘 안 되는 요청:
- 로그인이나 개인 계정이 필요한 서비스(키를 직접 주지 않으면 AI가 쓸 수 없습니다)
- iOS에만 있는 기능(단축어, 잠금 화면 위젯 등)

## 2-A. 프롬프트 복사 (무료)

1. **프롬프트 복사 (무료)** 탭을 고릅니다.
2. **프롬프트 복사**를 누릅니다. 요청과 함께 규칙, 그리고 이 앱이 실제로 지원하는 API 목록이 복사됩니다.
3. AI 채팅 앱에 붙여 넣고 보냅니다.
4. 받은 답을 **통째로** 복사해 **AI의 답** 칸에 붙여 넣습니다. 설명 글이 섞여 있어도 앱이 ```javascript 부분을 찾아 씁니다.
5. **실행해 보기**를 누릅니다.
   - **잘 실행됩니다**: 미리보기를 확인하고 3단계로 갑니다.
   - **아직 실행되지 않습니다**: **고쳐 달라는 프롬프트 복사**를 눌러, 같은 채팅에 붙여 넣습니다. 오류 내용과 코드가 함께 들어 있습니다. 새 답을 다시 붙여 넣고 실행해 보세요.

## 2-B. 앱에서 바로 (API 키)

1. **앱에서 바로 (API 키)** 탭에서 **서비스**를 고릅니다.
2. **API 키**를 붙여 넣고 **OK**를 누릅니다. 키는 이 폰에 암호화해 저장하고, 고른 서비스에만 보냅니다. 스크립트의 `Keychain`으로는 이 키를 읽을 수 없습니다.
3. **모델** 옆 **목록**을 눌러 이 키로 쓸 수 있는 모델을 고릅니다. 목록은 서비스에서 바로 받아 오므로 늘 최신입니다.
4. **만들기**를 누릅니다. 앱이 AI에 요청 → 받은 스크립트 실행 → 오류가 나면 오류를 보내 고치기를 최대 3번 반복합니다.

### API 키 받기

| 서비스 | 받는 곳 | 메모 |
|---|---|---|
| Gemini | [Google AI Studio](https://aistudio.google.com/apikey) | 무료 등급이 있어 처음 써 보기 좋습니다(하루·분당 요청 수 제한). 무료 등급은 보낸 내용이 서비스 개선에 쓰일 수 있습니다. |
| Claude | [Anthropic Console](https://console.anthropic.com/) | 쓴 만큼 냅니다. 새 계정에 체험 크레딧이 있을 수 있습니다. |
| OpenAI | [OpenAI Platform](https://platform.openai.com/api-keys) | 쓴 만큼 냅니다. |

ChatGPT Plus, Claude Pro 같은 채팅 구독과 API 요금은 별개입니다. 구독만 있다면 **프롬프트 복사**를 쓰세요.

모델 고르기: 코드를 잘 쓰는 모델일수록 한 번에 성공합니다. 각 서비스의 빠르고 저렴한 모델(Flash, Haiku, mini 등)로 시작해서, 자꾸 실패하면 상위 모델로 바꿔 보세요.

## 3. 저장하기

- 미리보기는 **중간 크기** 위젯으로 실제 실행한 결과입니다. 네트워크 데이터도 실제 값입니다.
- **사용:** 줄에 스크립트가 쓰는 기능(네트워크, 위치, 캘린더 등)이 보입니다. 저장하기 전에 요청한 것과 맞는지 확인하세요.
- **스크립트 이름**을 정하고 **저장하고 열기**를 누르면 편집기가 열립니다. 같은 이름이 있으면 뒤에 숫자가 붙습니다.
- 홈 화면에 ScriptWidget 위젯을 추가하고 이 스크립트를 고르면 끝입니다.

## 안 될 때

| 증상 | 해결 |
|---|---|
| "답에서 스크립트를 찾지 못했습니다" | 답 전체를 붙여 넣으세요. AI가 코드를 안 줬다면 "코드 블록 하나로 전체 스크립트를 줘"라고 다시 요청하세요. |
| "AI 요청에 실패했습니다: HTTP 400/401/403" | 키가 틀렸거나, 그 키로 쓸 수 없는 모델입니다. **목록**에서 모델을 다시 고르세요. |
| "HTTP 429" | 요청 수 한도에 걸렸습니다(무료 등급에서 흔함). 잠시 뒤 다시 하거나 다른 모델을 고르세요. |
| 3번 시도해도 실패 | 요청을 더 구체적으로 바꾸거나(데이터 출처, 배치), 상위 모델로 바꾸거나, **프롬프트 복사**로 대화하며 고쳐 보세요. |
| 앱에서는 되는데 위젯에서 `–`나 오류 | 위젯은 백그라운드에서 실행됩니다. 위치·캘린더 같은 권한이 필요한지 **설정 → 권한**을 확인하세요. |
| 결과가 마음에 안 듦 | 편집기에서 직접 고치거나, 요청에 "글자를 더 크게", "배경을 검게"처럼 덧붙여 다시 만드세요. |

## 무엇이 전송되나

- **보내는 것**: 요청 문장, 규칙, 이 앱의 API 목록. 오류가 나면 그 스크립트와 오류 메시지.
- **보내지 않는 것**: 다른 스크립트, 실행 기록, 파일, 위치·연락처 같은 개인 데이터.
- 생성된 스크립트가 위젯으로 실행될 때 하는 일(예: 날씨 API 요청)은 일반 스크립트와 같습니다.
