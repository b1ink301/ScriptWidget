# URL(JSON)로 위젯 만들기

코드를 쓰지 않고, 웹 API가 돌려주는 JSON에서 값을 골라 홈 화면 위젯을 만듭니다. 날씨, 환율, 코인 시세, GitHub 별 개수처럼 **주소 하나로 숫자나 글자를 돌려주는 API**라면 무엇이든 쓸 수 있습니다.

만든 위젯은 일반 디자이너 위젯입니다. 나중에 디자이너에서 글자 크기·색·배치를 바꾸거나 다른 요소를 더할 수 있습니다.

## 빠르게 해 보기

1. **내 스크립트** 탭 → 오른쪽 위 **+ 새 스크립트** → **🔗 URL(JSON)로 만들기**
2. 아래쪽 **예시** 중 하나를 누릅니다(예: **서울 날씨**). 주소 칸이 채워집니다.
3. **불러오기**를 누르면 응답에 든 값이 목록으로 나옵니다.
4. 보이고 싶은 값을 체크합니다(최대 6개). 예: `current.temperature_2m`, `current.relative_humidity_2m`
5. **제목**을 원하는 이름으로 바꾸고(비워 두면 주소의 호스트 이름) **만들기**를 누릅니다.
6. 디자이너가 열리고 위쪽 미리보기에 실제 값이 보입니다. 마음에 들게 고친 뒤 뒤로 나가면 자동으로 저장됩니다.
7. 홈 화면에 ScriptWidget 위젯을 추가하고 이 스크립트를 고르면 끝입니다.

## 화면 설명

### 주소와 불러오기

- `https://`로 시작하는 주소를 넣습니다. 브라우저에서 열었을 때 `{ ... }`나 `[ ... ]`로 시작하는 글자가 보이면 JSON입니다.
- **불러오기**는 지금 한 번 요청해서 어떤 값이 있는지 보여 주기만 합니다. 위젯은 갱신될 때마다 같은 주소에 다시 요청합니다.

### 값 목록

각 줄은 위쪽 **경로**와 아래쪽 **지금 값**으로 되어 있습니다.

| 응답 | 목록에 나오는 경로 | 지금 값 |
|---|---|---|
| `{"data": {"amount": "76712.6"}}` | `data.amount` | 76712.6 |
| `{"rates": {"KRW": 1342.9}}` | `rates.KRW` | 1342.9 |
| `{"items": [{"title": "첫째"}, {"title": "둘째"}]}` | `items.0.title`, `items.1.title` | 첫째, 둘째 |

- **경로**는 바깥 이름부터 점(`.`)으로 이어 붙인 것입니다.
- **배열**(`[ ... ]`)은 순서 번호를 씁니다. 0부터 세고, 목록에는 앞의 3개만 보입니다. `items.0.title`은 "첫 번째 항목의 제목"입니다.
- 긴 글자는 목록에서 줄여 보이지만, 위젯에는 전체 값이 들어갑니다.
- 값이 아주 많은 응답은 앞의 200개까지만 보입니다.

### 배치

- **하나만 고르면**: 제목 아래에 그 값을 크게 보여 줍니다. 별 개수, 가격처럼 숫자 하나를 볼 때 좋습니다.
- **여러 개 고르면**: `이름 … 값` 줄을 쌓습니다. 이름은 경로의 마지막 부분을 읽기 쉽게 바꾼 것입니다(`stargazers_count` → "Stargazers count", `windSpeed` → "Wind speed"). 디자이너에서 한국어 이름으로 바꿔도 됩니다.
- 자동 갱신은 **30분**으로 잡힙니다. 디자이너의 **구조**에서 **🧩 위젯**을 골라 **자동 갱신 요청**에서 바꿀 수 있습니다.

## 예시

앱의 예시 버튼과 같은 주소입니다. 모두 가입이나 API 키가 필요 없습니다.

| 예시 | 주소 | 고를 값 |
|---|---|---|
| 서울 날씨 ([Open-Meteo](https://open-meteo.com/)) | `https://api.open-meteo.com/v1/forecast?latitude=37.57&longitude=126.98&current=temperature_2m,relative_humidity_2m,wind_speed_10m` | `current.temperature_2m`, `current.relative_humidity_2m`, `current.wind_speed_10m` |
| 달러 환율 ([Frankfurter](https://frankfurter.dev/)) | `https://api.frankfurter.dev/v1/latest?base=USD&symbols=KRW,JPY,EUR` | `rates.KRW`, `rates.JPY`, `rates.EUR` |
| 비트코인 시세 (Coinbase) | `https://api.coinbase.com/v2/prices/BTC-USD/spot` | `data.amount` |
| GitHub 저장소 | `https://api.github.com/repos/b1ink301/ScriptWidget` | `stargazers_count`, `forks_count`, `open_issues_count` |

다른 도시의 날씨는 주소의 `latitude`(위도)와 `longitude`(경도)를 바꾸면 됩니다. 다른 저장소는 `repos/` 뒤를 `소유자/저장소`로 바꿉니다.

## 꾸미기

**만들기** 뒤에 열리는 디자이너에서 일반 위젯처럼 고칩니다.

- **단위 붙이기**: 값 텍스트를 골라 **속성**의 **문구** 칸을 `{value}°C`, `₩{value}`, `⭐ {value}`처럼 바꿉니다. `{value}` 자리에 값이 들어갑니다.
- **경로 바꾸기**: 같은 텍스트의 **JSON 주소**와 **값 경로** 칸에서 직접 고칠 수 있습니다.
- **값 더하기**: 아래 **+ 요소** → **데이터 블록** → **JSON 값 (URL)**을 넣고 같은 주소와 다른 경로를 적습니다. 같은 주소의 값은 몇 개를 넣어도 갱신할 때 **한 번만** 요청합니다.
- **탭하면 열 주소**: **🧩 위젯**의 **탭하면 열 주소**에 웹 페이지(예: 날씨 사이트)를 넣으면 위젯을 눌렀을 때 그 페이지가 열립니다.

## 안 될 때

| 증상 | 원인과 해결 |
|---|---|
| "JSON을 불러오지 못했습니다: HTTP 401" 또는 403 | API 키나 로그인이 필요한 주소입니다. 주소에 키를 넣는 방식(`?appid=…`, `?key=…`)이면 키를 포함한 주소를 넣으세요. 헤더로 키를 보내야 하는 API는 이 기능으로 만들 수 없으니 코드로 작성하세요. |
| "HTTP 404" | 주소가 틀렸습니다. 브라우저에서 먼저 열어 보세요. |
| "Unexpected JSON token" 같은 오류 | JSON이 아닌 웹 페이지(HTML) 주소입니다. 서비스의 **API** 주소를 찾아 넣으세요. |
| 이 응답에는 값이 없습니다 | 빈 객체(`{}`)나 빈 배열(`[]`)이 왔습니다. 주소의 조건(날짜, 검색어 등)을 확인하세요. |
| 위젯에 `–`가 보임 | 갱신할 때 값을 가져오지 못했습니다. 네트워크가 없거나, 서버가 응답 형태를 바꿨거나, 그 위치의 값이 사라졌습니다. 디자이너에서 미리보기를 확인하고 경로를 고치세요. |
| 목록의 순서 번호가 가리키는 항목이 바뀜 | 배열은 순서로만 고릅니다(`items.0`은 "지금 첫 번째"). 새 항목이 앞에 붙는 API(최신 글 목록 등)라면 위젯에는 항상 그때의 첫 번째가 보입니다. |
| 값이 늦게 바뀜 | 갱신 간격(기본 30분)과 Android의 절전 정책을 따릅니다. 바로 보려면 위젯을 탭하세요. 자세한 동작은 README의 **백그라운드 갱신 정책**을 보세요. |

## 주의할 점

- 주소에 API 키를 넣으면 그 키는 스크립트 코드 안에 그대로 저장됩니다. 스크립트를 내보내거나 갤러리에 올릴 때는 키를 지우세요. (진단 정보 내보내기는 주소의 `?` 뒤를 가립니다.)
- 무료 API는 요청 횟수 제한이 있을 수 있습니다. 갱신 간격을 너무 짧게 잡지 마세요.
- 더 복잡한 계산(두 값의 차이, 날짜 변환 등)이 필요하면 **코드** 버튼으로 생성된 Scriptable 코드를 보고, 편집기에서 직접 고쳐 쓸 수 있습니다. 직접 고친 스크립트는 그 뒤로 편집기로 열립니다.
